BƯỚC 3 — ĐƯA VIDEO LÊN WEB detpro.vercel.app (#153)
-------------------------------------------------
1. Mở thư mục Google Drive "DetProMedia" (thư mục đã khai trong client\src\components\HocKienThuc\config.js).
2. Kéo thả tệp  renders\dp\<bài>--w01.mp4  vào đó. GIỮ NGUYÊN TÊN (vd. ielts-task2-guide--w01.mp4).
   (#165) Có thể chia DetProMedia thành thư mục con:  video\ (mp4)  ·  img\ (jpg ảnh bìa)  ·  audio\ (mp3).
   Web đọc cả thư mục con (trừ thư mục tên "audio" — web chưa dùng, bỏ qua cho trang mở nhanh).
   Thư mục con nằm TRONG DetProMedia nên tự theo quyền chia sẻ; không cần đổi mã thư mục trong config.js.
   - Đã có tệp cũ cùng tên: xoá/đổi tên tệp cũ, hoặc dùng "Quản lý phiên bản → Tải lên phiên bản mới".
     Drive tự thêm " (1)" vào tên tệp trùng → web KHÔNG tìm thấy.
3. Chờ Drive xử lý video (vài phút; mở thử trên Drive phát được là xong).
4. Mở trang bài trên detpro.vercel.app → bấm tải lại (F5) → khung "Xem tóm tắt" hiện dưới tên bài.
   Không cần build/deploy lại web: web tự tìm tệp theo tên mỗi lần mở trang.

Không hiện video? Kiểm lần lượt:
- Thư mục DetProMedia chia sẻ "Bất kỳ ai có đường liên kết — Người xem" (tệp con tự theo thư mục).
- Tên tệp đúng tuyệt đối:  <tên bài>--w01.mp4  (chữ thường, hai gạch ngang, không dấu cách, không "(1)").
- Khoá API trong Google Cloud: bật "Google Drive API"; mục giới hạn trang web (HTTP referrers) phải có
  https://detpro.vercel.app/*  (và http://localhost:3000/* khi chạy thử trên máy).
- Bài đó đã có trên web (trang bài mở được).
- Mở F12 → Console/Network: lỗi 403 ở googleapis.com = khoá API chưa cho phép trang detpro.vercel.app.

TĂNG TỐC RENDER (#150)
---------------------
- Mặc định đã bật GPU (--gl=angle) và tự chọn số tab song song (tối đa 4) theo CPU + RAM trống.
  Dòng đầu khi render ghi rõ:  "... · 3 tab · GPU angle".
- Đóng bớt Chrome / VS Code / Kokoro trước khi render → còn nhiều RAM → được nhiều tab → nhanh hơn.
- Tự đặt số tab:      npx tsx render-CSK004.js --only=<bài>--w01 --scale=2/3 --concurrency=4
- Lỗi GPU / tab sập:  thêm  --gl=swangle  (chỉ CPU, chậm hơn nhiều) hoặc  --concurrency=1
- Bản xem nhanh 0.5 nhanh gấp đôi bản 2/3.
